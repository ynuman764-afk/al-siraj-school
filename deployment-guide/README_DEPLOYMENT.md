# Al-Siraj Model High School - Easy Step-by-Step Deployment Guide
# GitHub اور Vercel پر ویب سائٹ فری لائیو کرنے کا سب سے آسان طریقہ (اردو و رومن اردو)

اگر آپ کو پہلے GitHub یا Vercel کا تجربہ نہیں ہے تو پریشان ہونے کی بالکل ضرورت نہیں! یہ گائیڈ آپ کو **A to Z** آسان ترین زبان میں سمجھائے گی کہ آپ کس طرح اپنی اسکول کی ویب سائٹ کو چند منٹوں میں لائیو کر سکتے ہیں۔

---

## 💡 بنیادی تصور (GitHub اور Vercel اصل میں کیا ہیں؟)

1. **GitHub کیا ہے؟**  
   جیسے آپ Google Drive یا Dropbox پر اپنی فائلیں اور تصاویر رکھتے ہیں، بالکل اسی طرح GitHub ایک مفت کلاؤڈ اسٹوریج (تجوڑی) ہے جہاں آپ اپنی ویب سائٹ کا کوڈ محفوظ رکھتے ہیں۔
   
2. **Vercel کیا ہے؟**  
   Vercel ایک ایسا طاقتور مفت پلیٹ فارم ہے جو GitHub سے آپ کے اسکول کا کوڈ اٹھا کر اسے پوری دنیا میں ہر موبائل اور کمپیوٹر پر چلانے کے لیے ایک مفت ویب ایڈریس (جیسے `https://al-siraj-high-school.vercel.app`) بنا دیتا ہے۔

---

## 🌟 طریقہ نمبر 1: سب سے آسان طریقہ (بغیر کسی کمانڈ کے - Drag & Drop / Browser)

اگر آپ کو کمانڈ لائن (Terminal) مشکل لگتی ہے، تو آپ ماؤس کے ذریعے براہ راست ویب براؤزر سے یہ کام کر سکتے ہیں:

### مرحلہ 1: GitHub پر فری اکاؤنٹ بنائیں
1. اپنے براؤزر میں [https://github.com](https://github.com) کھولیں۔
2. **"Sign up"** پر کلک کریں۔
3. اپنا ای میل (Email) اور پاس ورڈ درج کریں اور اکاؤنٹ بنا لیں۔
4. آپ کے ای میل پر ایک ویریفکیشن کوڈ آئے گا، وہ ڈال کر لاگ ان ہو جائیں۔

### مرحلہ 2: GitHub پر نیا پروجیکٹ (Repository) بنائیں
1. GitHub کے ہوم پیج پر اوپر دائیں کونے میں **"+"** کے نشان پر کلک کریں اور **"New repository"** منتخب کریں۔
2. **Repository name** میں لکھیں: `al-siraj-school`
3. اسے **Public** ہی رہنے دیں۔
4. نیچے سبز رنگ کے بٹن **"Create repository"** پر کلک کریں۔

### مرحلہ 3: پروجیکٹ کی فائلیں اپلوڈ کریں
1. نئے پیج پر آپ کو ایک لنک نظر آئے گا: **"uploading an existing file"**، اس پر کلک کریں۔
2. اپنے اسکول پروجیکٹ کی تمام فائلیں (src, package.json, index.html وغیرہ) سلیکٹ کر کے براؤزر میں ڈریگ اینڈ ڈراپ (Drag & Drop) کر دیں۔
3. نیچے سبز بٹن **"Commit changes"** پر کلک کریں۔  
   *(مبارک ہو! آپ کا تمام کوڈ GitHub پر محفوظ ہو گیا)*۔

### مرحلہ 4: Vercel پر جا کر 1 منٹ میں لائیو کریں
1. اپنے براؤزر میں [https://vercel.com](https://vercel.com) کھولیں۔
2. **"Sign Up"** یا **"Log In"** پر کلک کریں اور **"Continue with GitHub"** منتخب کریں۔
3. GitHub آپ سے اجازت مانگے گا، **"Authorize Vercel"** پر کلک کر دیں۔
4. لاگ ان ہوتے ہی ڈیش بورڈ پر **"Add New..."** بٹن پر کلک کریں اور **"Project"** منتخب کریں۔
5. آپ کو آپ کی بنائی ہوئی ریپازیٹری `al-siraj-school` نظر آئے گی، اس کے سامنے **"Import"** پر کلک کریں۔
6. اگلے صفحے پر Vercel خودکار طور پر **Vite** کو پہچان لے گا۔ آپ کو کسی سیٹنگ کو چھیڑنے کی ضرورت نہیں!
7. سیدھا **"Deploy"** کے نیلے بٹن پر کلک کریں۔
8. صرف 45 سے 60 سیکنڈ انتظار کریں، اسکرین پر آتش بازی (Confetti) چلے گی اور آپ کو آپ کا لائیو ویب سائٹ لنک مل جائے گا:  
   👉 `https://al-siraj-school.vercel.app`

## ⚡ طریقہ نمبر 2: Git کمانڈز کے ذریعے (برائے ڈویلپرز / تیز ترین)

اگر آپ ٹرمینل یا VS Code استعمال کر رہے ہیں:

1. ٹرمینل کھولیں اور پروجیکٹ کے فولڈر میں یہ کمانڈز چلائیں:
```bash
git init
git add .
git commit -m "Al-Siraj Model High School Initial Release"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/al-siraj-school.git
git push -u origin main
```
2. Vercel ڈیش بورڈ پر جا کر **"Import"** کریں اور **"Deploy"** دبا دیں۔

## 🗄️ مفت ڈیٹا بیس (Supabase / PostgreSQL) کیسے لگانا ہے؟

ہماری بنائی ہوئی ایپلیکیشن میں تمام ڈیٹا آپ کے براؤزر کے لوکل اسٹوریج میں خودکار محفوظ رہتا ہے۔ اگر آپ چاہتے ہیں کہ دنیا بھر سے لوگ جو بھی داخلہ فارم بھریں وہ ایک کلاؤڈ ڈیٹا بیس میں جائے:

1. [https://supabase.com](https://supabase.com) پر جائیں اور **"Start your project"** پر کلک کریں۔
2. اپنے GitHub اکاؤنٹ سے لاگ ان کریں۔
3. **"New Project"** بنائیں (نام: `al-siraj-database`) اور پاس ورڈ رکھیں۔
4. بائیں مینو سے **"SQL Editor"** پر کلک کریں۔
5. اس پروجیکٹ کے فولڈر `/deployment-guide/schema.sql` میں موجود تمام کوڈ کو کاپی کریں اور Supabase کے SQL Editor میں پیسٹ کر کے **"Run"** دبا دیں۔
6. آپ کے تمام ٹیبلز (Students, Admissions, Fees, Results) فوری تیار ہو جائیں گے!

## ❓ عام سوالات اور ان کے حل (Troubleshooting)

- **سوال: کیا Vercel کے پیسے لگتے ہیں؟**  
  **جواب:** بالکل نہیں! Vercel اسکولوں اور ذاتی پروجیکٹس کے لیے 100% مفت ہے، کوئی کریڈٹ کارڈ درکار نہیں۔

- **سوال: کیا بعد میں اپنی مرضی کی ڈومین (جیسے `alsirajschool.edu.pk`) لگا سکتے ہیں؟**  
  **جواب:** جی ہاں! Vercel کے Settings -> Domains میں جا کر آپ اپنی خریدی ہوئی کوئی بھی ڈومین بالکل مفت لنک کر سکتے ہیں۔

- **سوال: اگر میں ویب سائٹ میں بعد میں کوئی تبدیلی کروں تو کیا دوبارہ Deploy کرنا پڑے گا؟**  
  **جواب:** نہیں۔ جیسے ہی آپ GitHub پر نئی فائل یا کوڈ اپلوڈ کریں گے، Vercel خودکار طور پر 30 سیکنڈ میں لائیو ویب سائٹ کو اپڈیٹ کر دے گا!
